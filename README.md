# Arena do Conhecimento

Jogo educacional da EREM Clóvis Beviláqua com Matemática, Português, modo aleatório, ranking individual e por equipes, competições e painel administrativo.

## Publicação

1. Execute `supabase/schema.sql` no SQL Editor do Supabase.
2. Em Authentication, crie o usuário administrador com o mesmo e-mail de `ADMIN_EMAIL`.
3. Configure na Vercel as variáveis descritas em `.env.example`.
4. Importe este repositório na Vercel e publique.

As chaves e a senha do banco nunca devem ser adicionadas ao GitHub.
